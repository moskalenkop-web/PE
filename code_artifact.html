Розділ 1

Інформація та Дані

Зрозумійте фундаментальну різницю між поняттями інформації, даних і тим, як вони зберігаються в цифрових системах.

Що таке Дані?

Дані — це зафіксовані факти, сигнали або спостереження, представлені у формалізованому вигляді, при придатному для обробки та передачі (наприклад, сухі числа, набір символів чи пікселі).

Що таке Інформація?

Інформація — це осмислені та інтерпретовані дані, які зменшують невизначеність і несуть новий зміст для людини чи інтелектуальної системи.

Розділ 2

Архітектура Комп'ютера

Апаратна складова (Hardware). Базові компоненти класичної архітектури фон Неймана.

Процесор (CPU)

Мозок комп'ютера. Виконує арифметичні та логічні операції, керує потоком інструкцій у системі.

Оперативна Пам'ять (RAM)

Енергозалежна надшвидка пам'ять для тимчасового зберігання даних та програм, що виконуються зараз.

Накопичувач (SSD/HDD)

Енергонезалежна пам'ять для тривалого зберігання файлів, операційної системи та встановлених програм.

Материнська Плата

Головна друкована плата, яка фізично та електрично з'єднує між собою всі компоненти ПК.

Розділ 3

Системи Числення та Кодування

Як обчислювальні системи кодують числовий та текстовий контент.

Base-2

Двійкова Система

Використовує тільки дві цифри: 0 та 1. Ідеально підходить для електронних схем з двома станами (є напруга / немає напруги).

Число 9 = 10012
Base-8

Вісімкова Система

Використовує цифри від 0 до 7. Коротша форма запису двійкових даних (групування по 3 біти).

Число 9 = 118
Base-16

Шістнадцяткова Система

Використовує цифри 0-9 та літери A-F. Зручна для представлення адрес пам'яті та RGB кольорів у веб.

Число 255 = FF16

Кодування Тексту: ASCII та Unicode (UTF-8)

ASCII (8-бітний стандарт)

Містить 128 основних символів (латинські літери, цифри, розділові знаки). Кожен символ займає точно 1 байт.

Unicode / UTF-8 (Універсальний)

Підтримує понад 140 000 символів з усіх мов світу, емодзі та спеціальні знаки. Довжина символу становить від 1 до 4 байт.

Розділ 5

Алгоритми та Програмування

Фундаментальні конструкції створення алгоритмів та мови розробки програмного забезпечення.

1. Послідовність (Linear)

Інструкції виконуються крок за кроком, строго в тому порядку, у якому вони записані в програмі.

2. Розгалуження (Branching)

Виконання певної гілки коду залежно від перевірки умови (істина / хиба: if / else).

3. Цикл (Iteration)

Повторення конкретного блоку команд певну кількість разів або поки виконується умова (for / while).

Популярні Мови Програмування

Python

Простий синтаксис. Застосовується в штучному інтелекті, аналізі даних та веб-розробці.

JavaScript

Мова браузерів та веб-інтерфейсів. Робить сайти інтерактивними та динамічними.

C++

Високопродуктивна мова для розробки ігор, операційних систем та системного ПЗ.

Розділ 6

Комп'ютерні Мережі та Кібербезпека

Основи роботи мереж Інтернет та правила захисту даних у цифровому просторі.

Як Працює Інтернет?

  • • IP-адреса: Унікальний числовий ідентифікатор пристрою в мережі (наприклад, 192.168.1.1).
  • • DNS (Domain Name System): "Телефонна книга" Інтернету, яка перетворює назви сайтів (google.com) на IP-адреси.
  • • HTTP / HTTPS: Протоколи передачі веб-сторінок. HTTPS забезпечує шифрування трафіку.

Правила Цифрової Безпеки

  • • Складні паролі: Використовуйте комбінацію літер, чисел та символів не коротше 12 знаків.
  • • 2FA (Двофакторна автентифікація): Додатковий захист акаунту через підтвердження на смартфоні.
  • • Захист від Фішингу: Не переходьте за підозрілими посиланнями в листі або повідомленнях.
